# Конфигурация PCIe SOM-5871 — вариант «8 линий GPP» (Config K)

> Альтернативная конфигурация расширения SOM-5871 (модуль **с** PCIe-мостом
> PLX PEX8605, до ECOM-165390): **все 8 линий GPP** выведены на разъём
> (1× Gen3 x4 + 1× Gen3 x1 + 3× Gen2 x1), встроенный I210-AT отключён.
> Основано на User Manual Ed.1 §1.3.7 и Layout Checklist A101-3.

## 2. GPP и PEG на SOM-5871

- **GPP (General Purpose PCIe)** — 8 линий CPU (`GPP0…GPP7`) на стороне A/B.
  Выведены как `PCIE_TX/RX0…7` + `PCIE0_CLK_REF±`.
- **PEG (PCIe Graphics)** — 8 линий CPU (`PEG0…7`) на стороне C/D, выведены как
  `PEG_TX/RX0…7` + `PEG_LANE_RV#` (D54), `PEG_ENABLE#` (D97).
- **GbE I210-AT** — контроллер на самом модуле, питаемый PCIe-линией.

## 3. Конфигурации из User Manual Ed.1 (§1.3.7)

> **PCI Express x8** — 1 × PEGx8.
> **PCIe x1** — несколько программируемых комбинаций.

## 4. Ключевые наблюдения

1. **Все 8 линий GPP реально используются.** В Config A/B в списке x1 портов
   фигурируют `[0,1,2,3,4,6,7]` — 7 из 8 GPP; PEG x8 дополнительно даёт 8
   линий (C/D).
2. **LAN и расширение конкурируют за линии GPP.** I210 на модуле подключён
   **через PCIe-мост PLX PEX8605**, который сам занимает одну GPP-линию.
   Конфигурации с `LAN = YES` (A, C, F, I) оставляют меньше GPP под
   расширение; с `LAN = NO` (B, E, H, **K**) — больше.
3. **Config K — единственный вариант 8 линий GPP без LAN.**
   `x4=1 [3:0]` + `x1=4 [4,5,6,7]` = **8 линий GPP**, `LAN = NO`.

## 5. Config K в деталях

### 5.1 Что даёт

| Параметр | Значение |
|:---------|:---------|
| Слоты на несущей плате | **1× PCIe x4** (COMe порты 0,1,2,3) + **4× PCIe x1** (COMe порты 4,5,6,7) |
| Скорость x4-слота | **Gen3 × 4** |
| Скорость x1-слотов | **1× Gen3 (#5) + 3× Gen2 (#4, #6, #7)** |
| Итого GPP-линий на разъёме | **8** (5×Gen3: #0–#3 + #5; 3×Gen2: #4, #6, #7) |
| GbE I210 (модуль) | **недоступен** (`LAN = NO`) |
| PEG x8 (C/D) | остаётся **независимым** (MCIO) — см. §5.3 |

### 5.2 Физические контакты 8 линий GPP (Layout Checklist, A101-3)

| GPP # | TX (Row A) | RX (Row B) | Скорость / длина |
|:------:|:-----------|:-----------|:-----------------|
| 0 | A68 / A69 | B68 / B69 | Gen3, L < 9000 mils |
| 1 | A64 / A65 | B64 / B65 | Gen3, L < 9000 mils |
| 2 | A61 / A62 | B61 / B62 | Gen3, L < 9000 mils |
| 3 | A58 / A59 | B58 / B59 | Gen3, L < 9000 mils |
| 4 | A55 / A56 | B55 / B56 | **Gen2 only** (L > 4000 mils) |
| 5 | A52 / A53 | B52 / B53 | **Gen3** (L < 9000 mils, напрямую с SoC) |
| 6 | D19 / D20 | C19 / C20 | **Gen2 only** (L > 4000 mils) |
| 7 | D22 / D23 | C22 / C23 | **Gen2 only** (L > 4000 mils) |

- Общий такт: **`PCIE0_CLK_REF±`** — A88 / A89.
- В Config K линии **#0–#3** идут в x4-слот (Gen3), **#4, #5, #6, #7** — в
  4 x1-слота. Линия **#5 (A52/A53, B52/B53)** идёт **напрямую с SoC** и
  **Gen3**. Ограничены Gen2 только линии **#4, #6, #7** (пометка «PCIe Gen2
  only» в xlsx; L > 4000 mils — трасса через/до PCIe-моста PEX8605).
- В Config K x4-слот использует **COMe-порты 0–3**, а не 0–5 как в Config A.
  То есть линия **#5** в K «переезжает» в x1-группу (оставаясь Gen3).

### 5.3 Связь с PEG x8 (C/D)

PEG (C/D) — **отдельные 8 линий CPU**, не входящие в GPP-таблицу §1.3.7.
Config K не трогает PEG: **PEG x8 по-прежнему доступен** (MCIO). Итого при
Config K на несущей плате:

- 8× GPP (A/B): 1× Gen3 x4 + 1× Gen3 x1 (#5) + 3× Gen2 x1 (#4, #6, #7);
- 8× PEG (C/D): MCIO x8 (не зависит от выбора Config).

> «8 доступных линий» — это **GPP**; PEG x8 остаётся дополнительно.
> Если нужно **16 линий одновременно** (8 GPP + 8 PEG) — возможно, так как
> это разные CPU-домены (GPP — A/B, PEG — C/D).

### 5.4 Сравнение Config K с текущей концепцией

| | Текущая концепция (`hw/README.md`) | Config K |
|:--|:----------------------------------|:---------|
| GPP x4 | COMe 0–3 → U.2 (NVMe / дисковый модуль) | COMe 0–3 → U.2 (аналогично) |
| GPP x1 | COMe 4 → M.2 M-Key (1 линия) | COMe 4,5,6,7 → **4× x1** (M.2 M-Key + 3 других слота) |
| GPP #5 (A52/A53, B52/B53) | только до ECOM-165390 (мост); после — N/A | **используется** как x1 (**Gen3**, напрямую с SoC) |
| PEG x8 (C/D) | MCIO | MCIO (без изменений) |

## 6. Ограничения

1. **BIOS.** Config K помечен в Ed.1 без «Optional» (в отличие от Config I),
   но общая пометка раздела гласит: «Several configurable combinations may need
   BIOS modifications».
2. **Gen2 на части x1.** Линии **#4, #6, #7** — Gen2 only (5 GT/s); линия
   **#5** — **Gen3** (напрямую с SoC).
3. **CLK_REF общий.** Все 8 GPP-линий используют один `PCIE0_CLK_REF±`
   (A88/A89). Длина трассы до такта — 1000–12000 mils (Layout Checklist).
