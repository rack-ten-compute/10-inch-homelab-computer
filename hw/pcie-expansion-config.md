# Конфигурация PCIe SOM-5871 — вариант «8 линий GPP» (Config K)

> Анализ альтернативной конфигурации расширения: **все 8 линий GPP (General Purpose)**
> доступны на несущей плате, а GbE-интерфейс I210 с модуля снимается и
> переносится на чип в несущей плате. Основано на двух ревизиях User Manual
> (раздел *1.3.7 Expansion Interface*).

## 2. Что такое GPP и PEG на SOM-5871

- **GPP (General Purpose PCIe)** — 8 линий CPU (`GPP0…GPP7`) на стороне A/B.
  Выведены как `PCIE_TX/RX0…7` + `PCIE0_CLK_REF±`.
- **PEG (PCIe Graphics)** — 8 линий CPU (`PEG0…7`) на стороне C/D, выведены как
  `PEG_TX/RX0…7` + `PEG_LANE_RV#` (D54), `PEG_ENABLE#` (D97).
- **GbE I210-AT** — контроллер на самом модуле, питаемый PCIe-линией.

> ⚠️ **Терминология.** В пользовательском запросе линии названы «PGF». В
> документации SOM-5871 такого сокращения нет: имеются **GPP** (General Purpose)
> и **PEG** (Graphics). Здесь «8 линий PGF» интерпретируется как **8 линий GPP**
> (не PEG) — это соответствует конфигурации K. *Если имелось в виду другое — см. §7.*

Обе ревизии открывают раздел одинаково:

> **PCI Express x8** — 1 × PEGx8.

## 4. Чтение таблицы: ключевые наблюдения

1. **Все 8 линий GPP реально используются в конфигурациях.** В Config A/B (Ed.1)
   в списке x1 портов фигурируют `[0,1,2,3,4,6,7]` — т.е. 7 из 8 GPP; PEG x8
   дополнительно даёт 8 линий (C/D). В Ed.2 Config S вообще `x4=1 + x2=1`,
   т.е. 4+2 GPP-линии, без x1.
2. **LAN и расширение конкурируют за линии GPP.**
   - Ed.1: I210 на модуле подключён **через PCIe-мост PLX PEX8605**, который сам
     занимает одну GPP-линию. Конфигурации с `LAN = YES` (A, C, F, I) оставляют
     меньше GPP под расширение; с `LAN = NO` (B, E, H, **K**) — больше.
   - Ed.2 (после ECOM-165390, мост снят): I210 берёт **GPP5 напрямую от SoC**.
     Конфигурации с `LAN = NO` (L, O, Q, S) освобождают GPP5 под расширение.
3. **Config K — единственный «чистый» вариант 8 линий GPP без LAN.**
   `x4=1 [3:0]` + `x1=4 [4,5,6,7]` = **4 + 4 = 8 линий GPP**, `LAN = NO`.
   Это и есть «8 доступных линий» из запроса.

## 5. Вариант Config K в деталях

### 5.1 Что даёт

| Параметр | Значение (Ed.1, Config K) |
|:---------|:--------------------------|
| Слоты на несущей плате | **1× PCIe x4** (COMe порты 0,1,2,3) + **4× PCIe x1** (COMe порты 4,5,6,7) |
| Скорость x4-слота | **Gen3 × 4** |
| Скорость x1-слотов | **Gen2 × 4** |
| Итого GPP-линий на разъёме | **8** (4×Gen3 + 4×Gen2) |
| GbE I210 (модуль) | **недоступен** (`LAN = NO`) — требуется сетевой чип на несущей плате |
| PEG x8 (C/D) | остаётся **независимым** (MCIO) — см. §5.3 |

### 5.2 Физические контакты 8 линий GPP (Layout Checklist, A101-3)

| GPP # | TX (Row A) | RX (Row B) | Скорость / длина |
|:------:|:-----------|:-----------|:-----------------|
| 0 | A68 / A69 | B68 / B69 | Gen3, L < 9000 mils |
| 1 | A64 / A65 | B64 / B65 | Gen3, L < 9000 mils |
| 2 | A61 / A62 | B61 / B62 | Gen3, L < 9000 mils |
| 3 | A58 / A59 | B58 / B59 | Gen3, L < 9000 mils |
| 4 | A55 / A56 | B55 / B56 | **Gen2 only** (L > 4000 mils) |
| 5 | A52 / A53 | B52 / B53 | Gen2 only (L > 4000 mils) |
| 6 | D19 / D20 | C19 / C20 | **Gen2 only** (L > 4000 mils) |
| 7 | D22 / D23 | C22 / C23 | Gen2 only (L > 4000 mils) |

- Общий такт: **`PCIE0_CLK_REF±`** — A88 / A89 (L < 9000 mils, до моста).
- В Config K линии **#0–#3** идут в x4-слот (Gen3), **#4–#7** — в 4 x1-слота
  (Gen2). Линии #4–#7 физически «дальние» (до PEG-зоны D/C), поэтому
  ограничены Gen2 — это совпадает с колонкой «COMe Gen2 Port# = 4,6,7» таблицы.
- **Важно:** в Config K x4-слот использует **COMe-порты 0–3**, а не 0–5 как в
  Config A. То есть линия **#5 (A52/A53, B52/B53)** в K «переезжает» в x1-группу.

### 5.3 Связь с PEG x8 (C/D)

PEG (C/D) — **отдельные 8 линий CPU**, не входящие в GPP-таблицу §1.3.7.
Config K не трогает PEG: **PEG x8 по-прежнему доступен** (в текущей концепции —
MCIO). Итого при Config K на несущей плате:

- 8× GPP (A/B): 1× Gen3 x4 + 4× Gen2 x1;
- 8× PEG (C/D): MCIO x8 (не зависит от выбора Config).

> То есть «8 доступных линий» в запросе — это **GPP**; PEG x8 остаётся
> дополнительно. Если нужно **16 линий одновременно** (8 GPP + 8 PEG) —
> это возможно, так как это разные CPU-домены (GPP — A/B, PEG — C/D).

### 5.4 LAN на несущей плате (замена I210)

При Config K встроенный I210-AT отключён. Для сохранения сетевой функции
на несущую плату добавляется **отдельный сетевой чип**. Варианты (без привязки
к конкретному BOM, т.к. в `bom/` сетевых чипов пока нет):

| Вариант | Подключение | Комментарий |
|:--------|:------------|:------------|
| **2.5/5 GbE чип** (напр. Intel I225/I226, Realtek RTL8125B, Microchip LAN9253) | **PCIe x1 Gen1/Gen2** | Проще всего: занимает **одну** x1-линию Config K (#4–#7), не конфликтует с x4-слотом. Дает >1 GbE, как в запросе |
| 1 GbE чип (Realtek RTL8111H, IC Plus I210-совместимый) | PCIe x1 Gen1 | Тоже одна x1-линия |
| USB-3.0/3.1 GbE (RTL8153) | USB 3.x | Не требует PCIe, но USB-шлюз медленнее и нестабильнее |

> **Рекомендация по запросу:** 2.5/5 GbE чип на **PCIe x1** (линия GPP #4 или
> #6 — обе Gen2, чего достаточно для 2.5/5 GbE). Освобождает 3 других x1-слота
> под расширение.

### 5.5 Сравнение Config K с текущей концепцией

| | Текущая концепция (`hw/README.md`) | Config K |
|:--|:----------------------------------|:---------|
| GbE | I210-AT с модуля → 1× RJ45 | **нет с модуля** → чип на несущей плате (2.5/5 GbE на x1) |
| GPP x4 | COMe 0–3 → U.2 (NVMe / дисковый модуль) | COMe 0–3 → U.2 (аналогично) |
| GPP x1 | COMe 4 → M.2 M-Key (1 линия) | COMe 4,5,6,7 → **4× x1** (M.2 M-Key + 3 других слота) |
| GPP #5 (A52/A53, B52/B53) | только до ECOM-165390 (мост); после — N/A | **используется** как x1 (Gen2) |
| PEG x8 (C/D) | MCIO | MCIO (без изменений) |

## 6. Ограничения и риски

1. **Без моста (Ed.2 / после ECOM-165390) Config K формально не существует.**
   В Ed.2-таблице нет строки «x4=1[3:0] + x1=4[4,5,6,7] + LAN=NO» — ближайший
   аналог **Config Q** (`x4=1[3:0] + x1=2[4,5] + LAN=NO`, только 6 линий GPP)
   или **Config S** (`x4=1 + x2=1[5:4] + LAN=NO`, 6 линий GPP).
   *Для 8 линий GPP нужен модуль Ed.1 (с PEX8605) либо индивидуальная
   конфигурация BIOS (см. §3, «may need BIOS modifications»).*
2. **BIOS.** Config K помечен в Ed.1 без «Optional» (в отличие от Config I),
   но общая пометка раздела гласит: «Several configurable combinations may need
   BIOS modifications. Please contact Advantech sales or FAE». *Перед заказом
   модуля — уточнить у Advantech, что Config K поддерживается в текущей ревизии
   BIOS.*
3. **Gen2 на x1.** Линии #4–#7 — Gen2 only (5 GT/s). Для 2.5/5 GbE-чипа на x1
   этого достаточно (2.5 GbE ≈ 0.3 GT/s, 5 GbE ≈ 0.7 GT/s). Но для NVMe-устройств
   на x1 скорость будет ограничена Gen2 (~1 ГБ/с в каждую сторону).
4. **CLK_REF общий.** Все 8 GPP-линий используют один `PCIE0_CLK_REF±` (A88/A89).
   При разнесённых x4- и x1-слотах на несущей плате длина трассы до такта должна
   укладываться в 1000–12000 mils (Layout Checklist).
5. **LAN-чип на x1.** Занимает одну из 4 x1-линий. Если нужно **4 x1-слота
   полностью свободных** + LAN, то LAN придётся вынести на **x4-слот** (но
   тогда U.2/NVMe пострадает) или на **USB-шлюз**.

## 8. Вывод

Config K (Ed.1) — штатная конфигурация SOM-5871, при которой **все 8 линий GPP**
выведены на разъём (4× Gen3 x4 + 4× Gen2 x1), а встроенный I210-AT отключён.
Для сохранения (и улучшения) сетевой функции на несущую плату добавляется
отдельный 2.5/5 GbE чип, подключаемый по **PCIe x1** (любая из линий #4–#7).
PEG x8 (C/D) при этом остаётся доступным независимо.

Главные оговорки:
- Config K **штатно существует только в Ed.1** (модуль с PEX8605);
- после ECOM-165390 (Ed.2) эквивалент требует **индивидуального BIOS** (контакт
  с Advantech FAE);
- x1-линии #4–#7 ограничены **Gen2**;
- LAN-чип на x1 **занимает одну** из четырёх x1-линий.
