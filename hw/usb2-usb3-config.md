# Конфигурация USB SOM-5871 — 3× Type-A + 2× пин-хедера

> Конфигурация USB-интерфейсов несущей платы под **SOM-5871**: 3× stacked
> Type-A (Port 0/1 Gen2 + Port 2 Gen1, с USB 2.0) + 2× стандартных пин-хедера
> (как на материнских платах). Всего 3 разъёма Type-A + 2 пин-хедера.
> Хабы на модуле не поддерживаются.
>
> Основано на `hw/pinout.md` (Layout Checklist A101-3), User Manual Ed.2
> §1.3.10.3, спецификации SOM-5871 (стр. 2); по аналогии с разводкой
> SOM-DB5830 (`docs/SOM-5871/som-db5830/`, листы 6–10).

## 2. Что есть на модуле

| Блок | Кол-во | Примечание |
|:-----|:------:|:-----------|
| USB 3.1 Gen2 (10 Гбит/с) | 2 порта | Port 0/1, SuperSpeed + USB 2.0 |
| USB 3.1 Gen1 (5 Гбит/с) | 1 порт | Port 2, SuperSpeed + USB 2.0 |
| USB 3.1 Port 3 | 1 порт | **N/A на модуле** (C12-C13 / D12-D13 — N/A в A101-3) |
| USB 2.0 (от CPU) | 4 порта | USB0–USB3, 480 Мбит/с |
| USB 2.0 (от хаба на модуле) | 4 порта | USB4–USB7, **не выводятся** |

Итого на разъёме: 3× USB 3.1 (Gen2 ×2 + Gen1 ×1) + 8× USB 2.0 = 11 портов.
Для несущей платы: **3× USB 3.1 (Port 0-2) + 6× USB 2.0 (USB0,1,2,4,5,6,7)**.

## 3. Разъёмы и хедеры несущей платы

| № | Тип | USB 3.1 | USB 2.0 | OC# (пин модуля) |
|:-:|:----|:--------|:--------|:-----------------|
| 1 | 1× Type-A, stacked, вертикальный, угловой | Port 0 + Port 1 (2× Gen2) | USB 0 + USB 1 | `USB_0_1_OC#` (B44) |
| 2 | 1× Type-A, stacked, вертикальный, угловой | Port 2 (1× Gen1) | USB 2 | `USB_2_3_OC#` (A44) |
| 3 | 1× стандартный пин-хедер (как на материнских платах) | — | USB 4 + USB 5 | `USB_4_5_OC#` (B38) |
| 4 | 1× стандартный пин-хедер (как на материнских платах) | — | USB 6 + USB 7 | `USB_6_7_OC#` (A38) |

Итого: **3 разъёма Type-A + 2 пин-хедера**.

## 5. VBUS / защита от перегрузки (OC)

| Разъём | VBUS | OC-сигнал (пин модуля) |
|:-------|:-----|:-----------------------|
| 1 (Port 0-1, USB 0-1) | +5V от несущей платы (LDO RT9742AGJ5F, как на DB5830) | `USB_0_1_OC#` (B44) |
| 2 (Port 2, USB 2) | +5V от несущей платы (LDO RT9742AGJ5F, как на DB5830) | `USB_2_3_OC#` (A44) |
| 3 (USB 4-5) | +5V от несущей платы (LDO RT9742CGJ5F, как на DB5830) | `USB_4_5_OC#` (B38) |
| 4 (USB 6-7) | +5V от несущей платы (LDO RT9742CGJ5F, как на DB5830) | `USB_6_7_OC#` (A38) |

> OC# — активный-низкий сигнал «перегруз по току» от LDO (load switch с OC).
> USB 3.1: до 900 мА на порт (USB spec, SOM-DB5830 лист 10).

## 6. Примечания

- **USB 2.0 Port 3 не выводится** — Port 3 SS на модуле N/A
  (C12-C13 / D12-D13 в A101-3 — N/A), USB2-порт 3 (B42-B43) не подключается.
- **Хабы на модуле** (USB4-7) **не поддерживаются** — порты не выводятся.
- **USB Wake**: S0 из S3/S4 (User Manual Ed.2 §1.3.11.4) — дополнительных
  сигналов не требует.
- **LPM**: U0/U1/U2/U3 (§1.3.10.3); для Gen2 — сертифицированный кабель.
- **Redriver Gen2**: PI3EQX1004B1ZHEX (SOM-DB5830 U44/U45) — при трассировке
  > 6" или через stacked-разъём (Design Guide §2.5).
- **CMC**: 85 Ом (SS TX/RX), 100 Ом (USB 2.0 D+/D-), SOM-DB5830 листы 6–10.
- **ESD**: TPD4E02B04DQAR, ≤ 750 mil от разъёма (Design Guide §2.5.4, ≥ 8 кВ).

## 7. Связь с PCIe-конфигурацией

USB-интерфейсы **не пересекаются** с GPP/PEG — все 3× USB 3.1 (Port 0-2)
и 8× USB 2.0 (USB0-7) идут напрямую от CPU (SoC). Конфигурация PCIe
(Config A–K / L–S) **не влияет** на доступность USB-портов.

> См. [pcie-expansion-config.md](pcie-expansion-config.md).
