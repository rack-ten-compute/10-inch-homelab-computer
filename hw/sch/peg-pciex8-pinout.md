# PEG x8 → PCIe x8 (98-pin) — mapping для несущей платы

Вывод шины PEG x8 (PCIe x8) с разъёма COM Express (Rows C/D) SOM-5871 на разъём
PCIe x8 (98-pin, SFF-04822, правый угол) несущей платы. Направление: модуль —
endpoint (device), несущая плата — host. Передача от модуля (PEG_TX, ряд D)
заходит на разъём как **PRSNT** (device-RX), приём на модуле (PEG_RX, ряд C) —
**PRSNT** (device-TX). В отличие от MCIO (SFF-TA-1016) здесь нет отдельного
направления PER/PET и служебных линий SMBus/REFCLK/CBL_PRES# — только 8 диф.
пар, GND и питание 3.3V.

Источники:
- Пины модуля: [`pinout.md`](../pinout.md) / [`comexpress-abcd.md`](pinout/comexpress-abcd.md)
  (SOM-5871 A101-3, Layout Checklist).
- Пины разъёма: стандартная раскладка PCIe add-in card (SFF-04822, 98-pos,
  нижний ряд A1..A49 / верхний ряд B1..B49, хвост x8 = пины 37..74, см. §3).

## 1. Сигналы PEG x8 на разъёме COM Express (модуль)

| Lane | TX (ряд D) | RX (ряд C) |
|:----:|:----------|:----------|
| 0 | D52 (+) / D53 (−) | C52 (+) / C53 (−) |
| 1 | D55 (+) / D56 (−) | C55 (+) / C56 (−) |
| 2 | D58 (+) / D59 (−) | C58 (+) / C59 (−) |
| 3 | D61 (+) / D62 (−) | C61 (+) / C62 (−) |
| 4 | D65 (+) / D66 (−) | C65 (+) / C66 (−) |
| 5 | D68 (+) / D69 (−) | C68 (+) / C69 (−) |
| 6 | D71 (+) / D72 (−) | C71 (+) / C72 (−) |
| 7 | D74 (+) / D75 (−) | C74 (+) / C75 (−) |

Остальные пины C/D, относящиеся к PEG-группе:
- **D54 — `PEG_LANE_RV#`** (lane reversal), **D97 — `PEG_ENABLE#`** — не
  подключаются к разъёму PCIe x8, оставляются по схеме модуля (NC/по умолчанию).
- **D57 / D67 / D73 / D76 / D84 / D87 / D93 / D96 / D103** и аналогичные
  **C73 / C76 / C84 / C87 / C93 / C96 / C103** — GND-пины рядом с линиями,
  используются как return-масса для трасс (не обязательны к выводу на разъём).
- **C54 / C57 / D57 (N/C)** — MTD/TPM, к PCIe x8 не подключаются.

## 3. Примечания

- **Питание**: на стандартном PCIe x8 (SFF-04822) питание 3.3V подаётся на
  верхнюю часть разъёма (пины A1/B1). На SOM-5871 3.3V AUX берётся со схемы
  питания несущей платы (как в MCIO-варианте, A8 3V3_AUX). 12V — по
  необходимости (не выводится на PCIe x8).
- **REFCLK (100 МГц)**: на SOM-5871 REFCLK PCIe (A88/A89, `PCIE0_CLK_REF±`)
  выведен на разъём COM Express (ряд A), а не на PEG. Для PEG x8 REFCLK
  берётся со схемы тактового генератора несущей платы (как в MCIO-варианте,
  A11/A12). На разъёме PCIe x8 REFCLK не выводится (встроен в плату).
- **PERST#**: на SOM-5871 `CB_RESET#` (B50) выведен на разъём COM Express.
  Для PEG x8 PERST# берётся со схемы управления несущей платы (аналогично
  MCIO-варианту, B11). На разъёме PCIe x8 PERST# не выводится.
- **WAKE# / CLKREQ# / CBL_PRES#**: на разъёме PCIe x8 (98-pin) не выводятся —
  NC. На SOM-5871 `WAKE0#/WAKE1#` (B66/B67) остаются NC.
- **PEG_ENABLE# (D97) / PEG_LANE_RV# (D54)**: не подключаются к разъёму,
  оставляются по схеме модуля (NC/по умолчанию).
- **GND-пины рядом с линиями** (C73, C76, D57, D67, D73, D76 и т.п.) —
  используются как return-масса для трасс на несущей плате, но не обязательны
  к выводу на разъём (GND уже на A2/B2 и хвосте).
