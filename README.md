## 💡 Описание

**RACK-10** — это проект по разработке компактного серверного компьютера форм-фактора 10" (254 мм по ширине), который монтируется в стандартную 10-дюймовую раму (стойку). Устройство создано для энтузиастов, которым нужна производительная, но компактная вычислительная система для дома.

В отличие от громоздких 19-дюймовых серверов, RACK-10:

- Занимает вдвое меньше места по ширине
- Вписывается в интерьер (помещается в полку IKEA KALLAX)
- Сохраняет полную совместимость с сетевым и серверным оборудованием 10" формата

## 📐 Технические характеристики

| Параметр | Значение |
|----------|----------|
| **Форм-фактор** | 10" (совместимость с EIA-310) |
| **Ширина** | 254 мм (по стандарту) |
| **Высота** | 1U / 2U / 3U (на выбор) |
| **Глубина** | от 180 до 300 мм |
| **Платформа** | x86 / ARM (Raspberry Pi / Rockchip / NUC) |
| **Охлаждение** | Активное / Пассивное (в зависимости от TDP) |
| **Питание** | DC 12V / 19V или ATX (PicoPSU) |

## 🚀 Конфигурации

### Базовый (1U, до 15W TDP)

- Raspberry Pi 5 / Rockchip RK3588
- 2 × Ethernet (Gigabit)
- Пассивное охлаждение
- Питание от USB-C / 5V DC

### Средний (2U, до 65W TDP)

- Intel N100 / AMD Ryzen Embedded
- 2–4 × Ethernet (2.5GbE)
- Активное охлаждение (малошумный вентилятор)
- PicoPSU (12V)

### Продвинутый (3U, до 120W TDP)

- Intel Core i5/i7 / AMD Ryzen
- Возможность установки PCIe-карт
- 2 × SATA для NAS
- ATX-питание

## 🔧 Компоненты

- **Печатная плата** — кастомная или Mini-ITX/NUC-совместимая
- **Корпус** — алюминиевый/стальной/3D-печатный (модульная конструкция)
- **Крепление в раму** — стандартные рельсы 10" (совместимость с большинством стоек)
- **Передняя панель** — опционально: порты USB, кнопка питания, LED-индикация
