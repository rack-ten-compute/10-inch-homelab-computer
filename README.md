## 💡 Описание

**RACK-10** — это проект по разработке компактного серверного компьютера форм-фактора 10" (254 мм по ширине), который монтируется в стандартную 10-дюймовую раму (стойку). Устройство создано для энтузиастов, которым нужна производительная, но компактная вычислительная система для дома.

В отличие от громоздких 19-дюймовых серверов, RACK-10:

- Занимает вдвое меньше места по ширине
- Вписывается в интерьер (помещается в полку IKEA KALLAX)
- Сохраняет полную совместимость с сетевым и серверным оборудованием 10" формата

## 🚀 Конфигурации

Все конфигурации строятся на вычислительном модуле **Advantech SOM-5871**
(COM Express Basic Type 6) — AMD Ryzen Embedded V1000. Конфигурация меняется
выбором CPU (артикул модуля), ОЗУ и накопителей; несущая плата одна.

| Конфигурация | Модуль (CPU) | Ядер/потоков | TDP | ОЗУ |
|--------------|-------------|:------------:|:---:|-----|
| **Эко (пассивное охлаждение)** | SOM-5871VC-U0A1 (V1605B) | 4/8 | 12–25 Вт | до 32 ГБ DDR4 |
| **Средняя** | SOM-5871VC-U3A1 (V1202B) / SOM-5871VCX-U1A1 (V1404I) | 2/4, 4/8 | 12–25 Вт | до 32 ГБ DDR4 |
| **Максимальная** | SOM-5871VC-H3A1 (V1807B) / SOM-5871VC-H2A1 (V1756B) | 4/8 | 35–54 Вт | до 32 ГБ DDR4 |

Общее для всех конфигураций:

- 2× SATA III (M.2 2280 Key B + U.2), PCIe x4 под NVMe/U.2 и x1 под M.2 M-Key
- 2× USB 3.1 Gen2 + 1× USB 3.1 Gen1 (все Type-A, Gen1 — с портом USB 2.0), 4× USB 2.0
- GbE (Intel I210-AT), dual-channel LVDS (2× FPC-40) + DisplayPort
- SMBus / I2C / SPI / WDT / FAN / GPIO — сервисные хедеры
- Питание: Vin 8.5–20 В (+ VSB 4.75–5.25 В в режиме ATX)

Подробности по интерфейсам — в [hw/README.md](hw/README.md).

## 🔧 Компоненты

- **Вычислительный модуль** — Advantech SOM-5871 (COM Express Basic Type 6,
  AMD Ryzen Embedded V1000), крепление — разъём COM Express Type 6
  (Molex [3-1827253-6](bom/connectors/comexpress/3-1827253-6.pdf))
- **Несущая плата** — кастомная: M.2 2280 Key B, U.2, M.2 M-Key, 2× FPC-40
  (LVDS), RJ45, USB Type-A, HD Audio, сервисные пин-хедеры
  (GPIO/SPI/I2C/COM2)
- **ОЗУ** — 2× DDR4 SO-DIMM (на самом модуле)
- **Корпус** — 10" (254 мм), крепление в стойку EIA-310
- **Передняя панель** — опционально: порты USB, кнопка питания, LED-индикация
- **BOM** — каталог компонентов несущей платы: [bom/README.md](bom/README.md)
